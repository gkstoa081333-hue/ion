# 이온 신청 시스템 설치 (1단계)

| 파일 | 역할 | 주소 |
|---|---|---|
| `apply.html` | 참가 신청 페이지 (인스타 프로필 링크용) | `https://gkstoa081333-hue.github.io/ion/apply.html` |
| `admin.html` | 운영진 신청관리 (휴대폰용) | `https://gkstoa081333-hue.github.io/ion/admin.html` |
| `apps-script/Code.gs` | 구글 시트 백엔드 | 시트의 Apps Script에 붙여넣기 |
| `index.html` | 매칭앱 (기존, 변경 없음) | `…/ion/#admin` |

비용: 전부 0원 (GitHub Pages · 구글 시트 · Apps Script · Gmail 알림)

## 1. 구글 시트 + Apps Script (5분)
1. 이온 운영용 구글 계정으로 **빈 스프레드시트** 생성 → 이름: `이온 신청 명단`
2. 메뉴 **확장 프로그램 › Apps Script**
3. `Code.gs` 내용을 전부 붙여넣고 저장 (💾)
4. 왼쪽 **프로젝트 설정(⚙)** › 시간대 **(GMT+09:00) 서울**
5. 상단 함수 목록에서 `setup` 선택 → **실행** → 권한 허용
   - "확인되지 않은 앱" 경고가 나오면 **고급 › (프로젝트명)으로 이동** 클릭
   - 설정 / 타임 / 신청자 / 기록 탭이 생기고, **관리자 키**가 실행 로그에 표시됩니다
6. **배포 › 새 배포** › 유형 ⚙ **웹 앱**
   - 실행 사용자: **나** / 액세스 권한: **모든 사용자** → 배포
   - 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사

## 2. 페이지에 주소 연결
`apply.html`, `admin.html` 맨 아래 스크립트의
```js
const API_URL = '';
```
따옴표 안에 웹 앱 URL을 넣고 저장소에 올리면 1~2분 뒤 반영됩니다. (비워두면 데모 모드)

## 3. 시트에서 고칠 것
- **설정 탭:** 입금계좌, 운영진이메일, 문의, **환불규정(★ 실제 규정으로)**
- **타임 탭:** 기수·날짜·시간·장소·정원. 공개를 `N`으로 바꾸면 신청 페이지에서 숨김
- 모집 마감: 설정 탭 `모집상태`를 `닫힘`으로

## 4. 운영 흐름
1. 신청이 들어오면 운영진 메일로 알림
2. 통장 앱에서 `홍길동017` 같은 입금자명 확인 → 관리자 페이지에서 `017` 검색 → **입금확인** → 확정 문자 창이 바로 열림 → 전송
3. 기한까지 미입금 → 1시간마다 자동취소 → 같은 타임 대기 1번 자동 배정 + 메일 알림 → 관리자 페이지에서 **자리 확보 문자** 전송
4. 행사 전날: 확정 탭에서 각자 **D-1 안내** 전송
5. 행사 당일: 현황 카드의 **매칭앱 명단** → 매칭앱 참가자 탭 › 한 번에 붙여넣기

## 코드를 고친 뒤
Apps Script 수정 후에는 **배포 › 배포 관리 › ✏ › 버전: 새 버전 › 배포**를 해야 반영됩니다. URL은 그대로 유지됩니다.
