# 자동 문자 엔진 (구글 Apps Script + 솔라피)

1분마다 신청서를 확인해서 아래 문자를 솔라피로 보냅니다. 문구는 사이트의 `ion-sms.js`(관리자 수동 발송과 같은 문구)를 그대로 씁니다.

| 종류 | 언제 |
|---|---|
| 입금 안내 | 신청 직후 (입금대기) |
| 대기 안내 | 대기로 접수됐을 때 |
| 자리 확보 | 대기 → 입금대기로 배정됐을 때 |
| 참가 확정 | 관리자에서 입금확인 누른 뒤 |
| D-1 안내 | 행사 전날 18~22시, 확정자 전원 |

- 밤 22시~아침 8시에 생긴 문자는 8시에 보냄 (D-1 제외)
- 같은 사람에게 같은 종류는 한 번만 (`apps/{id}/sms/{종류}`에 발송 시각 기록)
- 켜기/끄기·시험 모드·종류 선택: 관리자 › 설정 › 📱 자동 문자
- 실제 발송을 켠 시각 **이후**의 신청·확정·배정만 보냄 (기존 신청자에게 갑자기 가지 않음)

## 설치 (처음 한 번, 10분)
1. Firebase 프로젝트(eon-signal) 소유자 구글 계정으로 https://script.google.com → **새 프로젝트** → 이름 `이온 자동문자`
2. ⚙️ 프로젝트 설정 → **"appsscript.json" 매니페스트 파일 표시** 체크 → 편집기에서 `appsscript.json` 내용을 이 폴더의 파일로 교체
3. `Code.gs` 내용을 `ion-auto-sms.gs`로 교체 → 저장
4. ⚙️ 프로젝트 설정 → **스크립트 속성** 3개 추가
   - `SOLAPI_KEY` : 솔라피 API Key
   - `SOLAPI_SECRET` : 솔라피 API Secret
   - `SENDER` : 등록한 발신번호 (숫자만, 예 01072954101)
5. 편집기 위쪽 함수 선택에서 **setup** → ▶ 실행 → 권한 검토 → 허용
6. (선택) **testSend** 실행 → 발신번호로 시험 문자 1통
7. 관리자 › 설정 › 📱 자동 문자에서 "엔진 연결됨" 확인 → **시험** 모드로 하루 지켜본 뒤 **실제 발송**

솔라피 키는 스크립트 속성에만 저장합니다. 코드·GitHub·Firebase에는 넣지 마세요.
