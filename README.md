# 이온 크리스천 소개팅 — 운영 시스템

대전·세종·청주 크리스천 청년 소개팅 **이온**의 신청·매칭·후기·운영을 한 곳에서 관리하는 웹앱입니다.
GitHub Pages(정적 호스팅) + Firebase Realtime Database / Authentication 으로 동작하며, 서버 비용은 들지 않습니다.

## 페이지
| 파일 | 대상 | 하는 일 |
|---|---|---|
| `apply.html` | 참가자 | 참가 신청(3단계) · 입금 안내 · 대기 신청 · 취소 요청 · 오픈채팅 문의 |
| `index.html?s=<타임ID>` | 참가자 | 행사 당일 1·2순위 투표 (테이블 QR) |
| `review.html?c=<기수>&t=<타임>` | 참가자 | 익명 후기 (문항은 관리자에서 편집) |
| `admin.html` | 운영진 | **신청**(입금확인·문자·타임 변경·겹침 경고·명단 표) · **후기**(필터·한눈에 보기·링크/QR·문항 편집) · **설정**(기수 개설·상태·대상 연령·장소) |
| `index.html#admin` | 운영진 | **매칭**(참가자·출석·투표·결과 표·안내/후속 안부 문자) |
| `privacy.html`, `terms.html` | 공개 | 개인정보처리방침 · 이용약관 |

공용 코드: `ion-store.js`(Firebase 연결·기본값·연령/후기 문항 도우미), `ion-a11y.js`(접근성 보조).
`ion-store.js`를 고치면 각 HTML의 `ion-store.js?v=…` 버전 값을 올려 캐시를 갱신합니다.

## 데이터 구조 (Firebase)
- `apply/config` 운영 설정(참가비·계좌·환불 규정·오픈채팅·후기 문항) — 공개 읽기
- `apply/slots/{id}` 기수·타임(날짜·시간·장소·정원·대상 연령·공개 여부) — 공개 읽기
- `apply/cohorts/{기수}` 기수 상태(모집 중·진행 예정·종료) — 운영진 전용
- `apply/apps/{ION-0001}` 신청서 · `apply/counts` 정원 카운트 · `apply/phones` 중복 신청 방지
- `sessions/{id}` 매칭 타임(명단·투표·발송 기록) — 신청 타임마다 `slot-{id}`로 자동 생성
- `reviews/{id}` 익명 후기
- `admins/{uid}: true` 운영진 계정

보안 규칙은 `database.rules.json` — 바꾸면 Firebase 콘솔 › Realtime Database › 규칙에 붙여넣고 **게시**합니다.

## 한 기수 운영 순서
1. **설정 › + 새 기수 개설** → 날짜·시간·장소·정원·대상 연령 입력 → 상태 **모집 중** → 저장 (매칭 타임 자동 생성)
2. 신청이 오면 **신청 탭**: 입금 안내 문자 → 입금 확인 → **입금확인** 버튼(확정 문자 이어서) · 겹침 경고는 **타임 변경**
3. 행사 전날: 확정 탭 › **이 목록 n명에게 문자 보내기** › D-1 안내
4. 당일: **매칭 › 참가자 탭** 출석 체크 → **투표 시작** → **마감** → 결과 탭에서 안내 문자 · **매칭 결과 표로 보기**
5. 이후: 후기 부탁 문구 발송 → 14일 뒤 **후속 안부** 배너 → 기수는 행사 다음날 자동 **종료**
